# Etapa 03 — Interface e identidade visual

## Entrega

A interface inicial define o sistema visual corporativo escuro do MaterialCRM e fornece navegação demonstrativa para as áreas que serão conectadas aos módulos futuros.

## Telas e interações

- **Login:** formulário de acesso demonstrativo, pronto para receber autenticação real na Etapa 04.
- **Dashboard:** indicadores demonstrativos, gráfico semanal e lista de atenção operacional.
- **Navegação lateral:** acesso visual às áreas principais do produto.
- **Seleção de filial:** menu para alternar a filial ativa.
- **Perfil:** resumo do usuário e saída da demonstração, que abre a tela de login.
- **Notificações:** painel com atualizações operacionais.

## Sistema visual

- Base em carvão e verde profundo, com um único acento verde-lima moderado.
- Tipografia de interface sem serifa, contraste alto e densidade adequada para operação diária.
- Componentes possuem estados de foco, clique e abertura de menus.
- Layout se adapta a telas menores, convertendo o conteúdo em coluna única.

## Limites

Os dados apresentados são demonstrativos. Persistência, login real, permissões, indicadores conectados ao banco e fluxos de operação serão introduzidos nas próximas etapas.
